# Report Export

The canonical public report is:

- `Threat_Intelligence_Report.md`

To generate a PDF locally, use one of the following methods once a converter is available:

```powershell
pandoc .\Threat_Intelligence_Report.md -o .\Threat_Intelligence_Report.pdf
```

or export the Markdown from your editor using a Markdown PDF extension.

The PDF is intentionally not included unless generated from the latest Markdown source.
